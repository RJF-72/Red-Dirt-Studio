# Red Dirt Rhythm Studio

A professional-grade Digital Audio Workstation (DAW) featuring industry-leading 0.4ms real-time latency, integrated AI vocal processing, and innovative workflow tools specifically designed for country, western, and roots music creators.

## Key Features

- **0.4ms RTL (Round-Trip Latency)** - Industry's lowest latency for true zero-latency monitoring
- **96kHz/64-bit audio processing** - Professional-grade sound quality
- **Jones County Vocal Repair (JCVR)** - Complete 7-stage AI-powered vocal restoration suite
- **Red Dirt Scripting Language (RDSL)** - Domain-specific language for audio automation
- **Integrated Teleprompter** - Synchronized lyric display for vocal tracking
- **Harmonic Identity Matrix** - BlueSteel/RedDirt/Longhorn tonal profiles
- **Neural-Parametric Behavior Engine** - AI/ML integration for intelligent processing
- **DFC-Class DSP Core** - 1000+ processing paths
- **Immersive Routing Matrix** - 7.1.4 surround capabilities
- **Export to multiple formats** - WAV, AIFF, FLAC, MP3, OGG

## System Requirements

- **OS:** Windows 10+, macOS 10.15+, Linux (modern distro), ChromeOS
- **Browser:** Chrome, Edge, Safari, Firefox (with WebAssembly & WebAudio support)
- **RAM:** 4GB minimum (8GB+ recommended)
- **Storage:** 2GB for application + space for audio files
- **Audio Interface:** ASIO/CoreAudio/WASM compatible device recommended

## Getting Started

1. Open `index.html` in a modern web browser
2. Allow microphone access if recording
3. Use the import button (📥) to load audio files
4. Arm tracks (REC button) and use transport controls to record/playback
5. Access AI features through the Jones County Vocal Repair panel
6. Use RDSL editor for advanced scripting and automation

## Development

This is a pure web application (HTML/CSS/JavaScript) that can be:
- Run directly in any modern browser
- Wrapped in Electron/NW.js for desktop deployment
- Deployed to any web server for online access

For desktop deployment with installer (.MSI, .PKG, etc.), you would first need to wrap this application in a desktop framework like Electron, then use platform-specific installer tools.
